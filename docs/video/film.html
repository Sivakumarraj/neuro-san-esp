The gap
neuro-san's designer builds one network. It never measures it.

agent_network_designer turns a sentence into a working multi-agent network. Nothing in neuro-san or neuro-san-studio scores one network against another.

So nobody can say whether four agents beat two for the same job, or which model each agent should run.

01 · Context, action, outcome
What is optimised, and against what?

Context — a question with a checkable answer. The search prescribes one network for all of them; the router in 04 prescribes per question.

Action — a neuro-san network: an agent_network_definition plus a model per agent. Whatever the search produces runs as an ordinary neuro-san network.

Outcomes — accuracy, tokens, dollars, model calls and agent count.

fitness = accuracy

02 · The surrogate
What does the Predictor actually predict?

Asked in review by a co-author of the ESP paper. The first version was not what ESP means by one: a single model trained on the already-scalarised fitness.

Now: one gradient-boosted regressor per outcome — accuracy, tokens — on 13 structural features. Agent count is counted, not predicted. Fitness is derived.

The split found a defect one number had hidden. Accuracy ranks well: +0.63 against a null of −0.07. Token cost is predicted backwards, −0.53, in 20 of 20 seeds — so it is left out of the ranking and published, not patched.

Below 8 measurements the Predictor refuses to fit, and the generation is reported as a random search.

03 · Replication
40 fresh questions, and a model control.

The control is the designer's shape with every specialist promoted to gpt-5.4-mini — to test whether a stronger model alone explains the gain.

vs the designer's shape: 9 questions to 1 · p = 0.0215 · 42% fewer tokens.

vs the model control: 7 to 1 · p = 0.0703 — not significant at 0.05 on 40 questions.

Promoting every specialist bought the designer's shape 2.5 points and more than doubled its cost.

04 · Cost
What does each right answer cost?

2cc4 uses 37% fewer tokens but costs 94% more a question (+72% a correct answer): its one document-reading agent runs a model 3.7× dearer per token.

A router sends a question up only when its text predicts a gain: 93.0% at $0.00186, 29% less than the strong network. The same share sent up at random: 88.2% (p = 0.0005).

It does not beat a one-line rule — two or more named entities, or an aggregate — which keeps 94.5% at $0.00226.

Two runs agreeing is a flag, not a gate: the designer's shape is right 96.3% of the time when its runs agree, 27.8% when they don't. All nine paid head-to-head stages cost $3.73 by neuro-san's own count.

05 · Production
Can it run unattended?

Event-invoked. neuro-san's own server fires the optimizer on a cron as user_id: system, with no client attached. Verified against neuro-san 0.6.95.

The model never chooses or spends. Two tools: RunWake ignores its arguments; ReportFinding can only draft. Silent unless something improved.

Built to be cut short. Preflight refuses a missing key, or every candidate would score zero and stay cached. A lease stops overlapping wakes; state is written atomically after every candidate.

The cache is keyed by genome hash, so no topology is paid for twice. Every paid run stops at its dollar cap, and resumes.

docker compose: state on a named volume, runs as uid 10001, publishes no port.

05 · Every push
CI holds the README to its evidence.

Actions pinned by commit, a read-only token, pip-audit on the lock the images ship, ruff, pymarkdown, neuro-san's HOCON validator, coverage ≥ 85% on Python 3.12 and 3.13, and an offline search that can genuinely fail.

A test recomputes every figure in the README and RESULTS from the committed logs — a claim that drifts from its evidence fails the build.

The paid same-budget experiment runs on GitHub Actions in resumable legs of up to 5 h 20 min.

Serve the winner: a browser page with request ids and an optional access token, neuro-san's accelerator UI, a plain registry, or a Hugging Face Space.

Said before a reviewer finds it
Where this is not ESP.

No learned Prescriptor. Prescription is seven mutation operators plus Pareto-front selection — nearer to LEAF (GECCO 2019), with agents where LEAF had layers.

The paid result does not test the Predictor. Offline it picks the best of three unseen networks 62% of the time — level with picking the one with the most agents.

One task domain, one generation of search on the held-out run, few models measured.

Not novel as an idea: AgentSquare (ICLR 2025) also searches agent designs with a predictor. What is new is doing it for neuro-san.
