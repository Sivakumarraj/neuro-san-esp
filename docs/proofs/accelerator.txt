Real questions over HTTP, through the real agents:

  T01, one hop -- "Who is the depot manager of Meridian Logistics depot D08?"
    evolved_reassign_model_3bf9c008  ->  "J. Vasquez"    entered at Coordinator
    seed_solo                        ->  "J. Vasquez"    entered at Answerer
    expected: J. Vasquez                                 both CORRECT

  The entry agent differs because the topology differs: the five-agent network
  routes through a Coordinator, the one-agent seed answers directly. Same
  question, same corpus, different network, and the genome is the only thing
  that changed.

  T04, two hops -- "Who manages the depot that services the contract with
                    client Dunmore Packaging?"
    evolved_reassign_model_3bf9c008  ->  "R. Halvorsen"                CORRECT
    expected: R. Halvorsen

  T07, three-hop full-corpus aggregation -- "Which client holds the Meridian
        Logistics contract with the highest annual value?"
    evolved_reassign_model_3bf9c008  ->  "Northwind Mills"               wrong
    seed_designer_shaped             ->  "Anvil Brewing"                 wrong
    expected: Copperfield Print

  T07 failing is the measurement reproducing, not the demo breaking. It is one
  of the two full-corpus aggregations that nearly every network in the
  population gets wrong or never finishes: answering it means about fourteen
  successive searches, because CorpusSearch returns three documents a query.
  In the committed run this same network's single miss out of seventeen was
  T07, answered "Bright Circuit" -- a different wrong answer today, which is
  what model nondeterminism looks like on a question none of them can do.

So what is verified here is the whole loop as a person meets it: a measured
population served as ordinary neuro-san agents, an accelerator UI listing all
twelve with the score each earned, and real questions answered correctly
through the real topologies -- including the one question the measurements say
they fail, failing.
