## Getting help

For bugs and feature requests, open an issue with a template:

- [Bug report](https://github.com/Sivakumarraj/neuro-san-esp/issues/new?template=bug_report.md)
- [Feature request](https://github.com/Sivakumarraj/neuro-san-esp/issues/new?template=feature_request.md)

Before reporting a run that failed, run `make check-key` and include its output. Remove API keys from anything
you paste.
